# Overview

This is a simple Hello World console program written in C#. When the program runs, it displays the message "Hello World!" on the screen.

The purpose of creating this software is to become familiar with the C# programming language and the basic development process for a C# application. Through this project, I learned how to set up the .NET development environment, create a C# console application, compile and run the program, and publish the source code to GitHub using Git.

[Software Demo Video](https://www.loom.com/share/0543703271ce45638887233a9ec18f21)

# Development Environment

I developed this software using Visual Studio Code as my code editor and PowerShell as my command-line environment. I used the .NET 10 SDK to create, compile, and run the application. I also used Git for version control and GitHub to host the source code in a public repository.

The program is written in C#. C# is an object-oriented programming language that runs on the .NET platform. This program uses the `Console.WriteLine()` method to display the "Hello World!" message in the console.
